# Daftari Pro

Hesabu za biashara kwenye simu: maduka (mauzo, stoo, madeni, ripoti) na mawakala wa pesa (floti, miamala, kamisheni, hesabu ya jioni).

- Mteja anajisajili mwenyewe, anapata siku 14 za majaribio, kisha analipa kwa mwezi.
- Kifurushi kikiisha, data inabaki salama lakini hawezi kurekodi mpaka alipie.
- Admin (barua pepe iliyo kwenye `config.js` na `firestore.rules`) anaona biashara zote, anathibitisha malipo, anawasha na kufunga.

## Mipangilio
1. `config.js`: weka bei, namba ya kulipia, WhatsApp yako na mipangilio ya Firebase.
2. Firebase → Firestore → Rules: bandika yaliyomo kwenye `firestore.rules`, kisha Publish.
